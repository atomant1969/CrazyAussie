Parent: Index

Tool: Interactive Checklist

Use this HTML page as the checklist reference. Use the interactive checklist tool when you want saved progress, notes, and three states: not started, in progress, completed.

Important: if a task feels vague, open the Interactive Checklist. Each task there includes a "How to do this" guide with small steps and a clear "Done when" condition.

Static checkboxes are binary only. The three-state workflow is handled in Interactive Checklist, where each task can be cycled through:

  1. Not started.
  2. In progress.
  3. Completed.
