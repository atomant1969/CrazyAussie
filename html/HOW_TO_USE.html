How To Use This Project

Parent: Index

Tool: Start Here HTML

Short Answer

If you downloaded this project from GitHub, open:

START_HERE.html

That file opens in a normal web browser and gives you clickable navigation to generated HTML pages.

Why Index.md May Look Like Plain Text

Index.md is a Markdown file. Markdown is easy to read and works well on GitHub, but on some computers it opens as plain text if there is no Markdown viewer installed.

That is normal. Nothing is broken.

For local browser use, open START_HERE.html and follow the links to the generated pages in the html folder.

Best Ways To Use The Project

Option 1: Use The Browser Start Page

Best for non-technical use.

  1. Download or clone the repo.
  2. Open the folder.
  3. Double-click START_HERE.html.
  4. Use the links to open the project index, checklist, and docs as browser-friendly HTML pages.

Option 2: Use GitHub

Best if viewing online.

  1. Open the repo on GitHub.
  2. Click Index.md.
  3. GitHub will render the Markdown as formatted pages.
  4. Click links between documents.

Option 3: Use VS Code

Best if editing the files.

  1. Open the folder in VS Code.
  2. Open Index.md.
  3. Use Markdown preview with Ctrl+Shift+V.
  4. Edit files as needed.

Option 4: Use A Markdown App

Good apps include:

  • Obsidian.
  • Typora.
  • MarkText.
  • VS Code.

Open the project folder as a vault/workspace and start at Index.md.

Checklist Progress

Markdown checkboxes may not save when clicked in a preview.

Use CHECKLIST_APP.html for real progress tracking. It saves:

  • checked tasks
  • in-progress tasks
  • notes
  • collapsed sections
  • scroll position

The Markdown checklist is binary. The HTML checklist uses three states: not started, in progress, and completed.

Progress is saved in the browser on that computer. Use Export Progress inside the checklist app if you want a backup.

Recommended Daily Workflow

  1. Open START_HERE.html.
  2. Open CHECKLIST_APP.html.
  3. Work from the current open tasks.
  4. Add notes as you go.
  5. Export progress occasionally.
  6. Use Index.md when you need to navigate the full planning system.

Turning This Project Into Videos

The planning system is also teaching material. Use CHANNEL_PLANNING_CURRICULUM.md to turn the creation of this plan into tutorials for other YouTubers.

Rebuilding The HTML Pages

If you edit the Markdown files, rebuild the browser pages with:

node build-html.js

This refreshes the generated files in the html folder.
